# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

We take the security of Fence seriously. If you discover a security vulnerability or algorithmic exploit that could compromise evidence auditing, please report it responsibly.

### How to Report
Please **do not** open a public issue for security vulnerabilities. Instead:
- Use GitHub Private Vulnerability Reporting on the repository.
- Or email the maintainers directly.

### What to Include
Please provide:
1. Description of the vulnerability or flaw.
2. Steps to reproduce or proof-of-concept score input.
3. Potential impact on downstream AI agents.

### Response Timeline
- We will acknowledge receipt of the report within 48 hours.
- We will provide a timeline for triage and patch release.
- A public security advisory will be issued alongside the release of a patch.
